# BOG AI — UX კვლევის პროტოტიპი

კლიკებადი HTML პროტოტიპი BOG-ის მობილური აპისთვის, AI ასისტენტით (BOG AI). განკუთვნილია UX კვლევისთვის:
რესპონდენტები ბმულს საკუთარ ტელეფონზე, მობილურ ბრაუზერში ხსნიან.

## სცენარები (ერთ ბმულზე)

- **ანაბრის გახსნა** — AI-ს რჩევა მთავარზე (უმოქმედო ნაშთი), „დამეხმარე არჩევაში" ტიპებზე, AI-ით შევსებული ფორმა, შეჯამება, წარმატება
- **კრიპტო** — ჩემი სივრცე → ინვესტიციები → კრიპტო; ფრომფთები, ანალიზი, მოქმედებები, წყაროები
- **ფინანსური მენეჯერი** — ჰაბი → ხარჯების ანალიზი, ნოემბრის ბიუჯეტი, დიდი გადახდის გაყოფა
- **ავტომატური გადარიცხვა** — მთავარზე AI-ს ბანერი → შევსებული ფორმა → „ვიპოვე კიდევ 2 მსგავსი"
- **ხელფასამდე გაფრთხილება**, **ბარათმა უარი თქვა**, **ადამიანთან გადართვა** — გარე მოვლენით იწყება (მკვლევრის მენიუ)

## მკვლევრისთვის

- **თავიდან დაწყება:** ეკრანის ზედა მარცხენა კუთხეზე 2 წამიანი დაჭერა
- **მკვლევრის მენიუ** (შეტყობინებების გამოძახება): ზედა მარჯვენა კუთხეზე 2 წამიანი დაჭერა
- პირდაპირ კონკრეტულ ეკრანზე: `?start=crypto`, `?start=hub` და ა.შ.

## გაშვება ლოკალურად

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

შემდეგ გახსენი `http://localhost:8000/prototypes/ai-crypto/` (ტელეფონზე — კომპიუტერის ლოკალური IP იმავე Wi-Fi-ში).

## სტრუქტურა

- `bog-ui/` — BOG-ის კომპონენტების ბიბლიოთეკა (Figma დიზაინ სისტემიდან)
- `prototypes/ai-crypto/` — პროტოტიპი: `index.html`, `app.js` (AI ფენა), `screens.js` (ეკრანები და ნავიგაცია), `ai-bank.js`, `pfm.js`, `support.js` (სცენარები და AI პასუხები), `bank.js` / `data.js` (ფეიკ მონაცემები)
- `prototypes/ai-crypto/vendor/open-bot-avatar/` — AI ქერექთერის რენდერი ([open-bot-avatar](https://github.com/DominikScholz/open-bot-avatar), MIT)

## ფონტები

BOG ფონტები ლიცენზირებულია და რეპოზიტორიაში არ არის. ლოკალურად ჩადე `bog-ui/fonts/`-ში (BOG-Regular.woff2 და ა.შ.); მათ გარეშე ბრაუზერი სათადარიგო ფონტს იყენებს.
