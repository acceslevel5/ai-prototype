BOG UI

Text area

Open in Figma ↗

For input longer than a few words that can span several lines — a comment, a description, a reason. Same states and validation as Text Input, plus a character counter. The box starts at 96 px and grows with the text up to data-rows lines, then scrolls.

Usage

<div class="bog-field" data-type="textarea">          <!-- data-validation · data-rows="3–8" (default 5) -->
  <label class="bog-field__box">
    <span class="bog-field__text">
      <span class="bog-field__label">Payment purpose</span>
      <textarea class="bog-field__input" placeholder="What is this payment for?" maxlength="140"></textarea>
    </span>
    <span class="bog-field__counter">0/140</span>
  </label>
  <p class="bog-field__message">Message text</p>
</div>
