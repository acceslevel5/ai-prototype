BOG UI

Range Slider

Open in Figma ↗

Picks a value — or a range between two values — by dragging along a line. While dragging, the handle gets an orange halo and a tooltip shows the value. Free, or snapping to 2–11 marked segments. Disabled greys it out. Each notch the handle passes plays a soft click that rises in pitch from left to right, with a haptic tick on phones.

Usage

<div class="bog-slider" data-format="{v} ₾" data-segments="5">      <!-- data-feedback="off | sound | haptic" -->
  <div class="bog-slider__track">
    <input type="range" min="0" max="50000" step="10000" value="10000" aria-label="From">
    <input type="range" min="0" max="50000" step="10000" value="30000" aria-label="To">      <!-- Range: second handle -->
  </div>
  <div class="bog-slider__amounts"><span>0 ₾</span><span>50,000 ₾</span></div>
</div>

Try it

Drag a handle or use the arrow keys. Sound plays once the page has had a tap or key press; haptics work on Android (vibration) and iOS 18+ Safari.
