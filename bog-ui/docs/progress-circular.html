Progress Circular

Open in Figma ↗

Compact progress in a ring — a count (Numeric "99+"), a part of a whole (Fraction "0/4") or a done mark (IconOnly). The dark arc is the progress; an optional lighter arc ahead of it marks the next milestone. Four sizes and five statuses; Inactive is grey.

Usage

<div class="bog-pcircle" data-size="large" style="--value: 70; --milestone: 85" role="progressbar" aria-valuenow="70">
  <svg viewBox="0 0 40 40" aria-hidden="true">
    <circle class="bog-pcircle__rail" cx="20" cy="20" r="19" pathLength="100"/>
    <circle class="bog-pcircle__milestone" cx="20" cy="20" r="19" pathLength="100"/>
    <circle class="bog-pcircle__progress" cx="20" cy="20" r="19" pathLength="100"/>
  </svg>
  <span class="bog-pcircle__text">3/4</span>
</div>
