BOG UI

OTP Verification

Open in Figma ↗

The one-time-code step: choose where to get the code (SMS or Email), type it, see where it went, and wait out the countdown before asking for a new one. States: counting down, sending (loading), expired, and ready to resend. Without the selector it's the "Hard" version — just the field and the message.

Usage

<div class="bog-otp">                                     <!-- data-state="loading | expired" · data-appearance="inverse" -->
  <fieldset class="bog-radio-group" data-direction="horizontal" data-deselectable="false">…SMS / Email…</fieldset>
  <div class="bog-field">…<input class="bog-field__input" inputmode="numeric" maxlength="4">…</div>
  <div class="bog-otp__info">
    <p class="bog-otp__sent">We've sent a verification code to ••• •• 56 78</p>
    <p class="bog-otp__expired">This verification code has expired</p>
    <p class="bog-otp__timer" data-otp-timer="35">Resend code in <b>00:35</b></p>
    <button type="button" class="bog-otp__resend">Resend code</button>
  </div>
</div>

Try it

The countdown is 10 seconds here; then Resend becomes active.
