BOG UI

Search input

Open in Figma ↗

Filters a list or starts a search. Small (40) or Large (56); on the page (grey fill) or over imagery and colour (Overlay, white with a shadow). Focusing it outlines the box and shows Cancel; typing adds a clear button.

Usage

<div class="bog-search">                     <!-- data-size="large" · data-placement="overlay" -->
  <label class="bog-search__box">
    <span class="bog-search__icon"></span>
    <input class="bog-search__input" type="search" placeholder="Search" aria-label="Search">
    <button type="button" class="bog-search__clear" aria-label="Clear"></button>
  </label>
  <button type="button" class="bog-search__cancel">Cancel</button>
</div>

Try it

Tap the field and type to filter. Clear keeps the keyboard up; Cancel empties the field and leaves it.
