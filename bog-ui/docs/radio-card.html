BOG UI

Radio Card

Open in Figma ↗

Choose exactly one option when each needs details to compare, like card delivery speed and price. Tapping a card selects it and clears the others in the group. Control on the left or the right; read-only on summary steps. Any number of choices → Checkbox Card.

Usage

<div class="bog-choice-card-group" data-deselectable="false">   <!-- data-state="error | readonly | skeleton" -->
  <label class="bog-choice-card">                           <!-- data-align="right" -->
    <input type="radio" class="bog-radio__input" name="addons">
    <span class="bog-choice-card__text">
      <span class="bog-choice-card__title">Travel insurance</span>
      <span class="bog-choice-card__desc">Covers the whole trip</span>
    </span>
    <span class="bog-choice-card__slot"><b>4.00 ₾</b><small>/month</small></span>
  </label>
  …
  <p class="bog-choice-card__message">Choose at least one option</p>
</div>
