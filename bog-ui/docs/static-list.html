BOG UI

Static List

Open in Figma ↗

Short read-only details with their values — loan terms, a payment breakdown — each row a label on the left and its value on the right. Rows don't react to taps; an optional info icon opens a Tooltip. Two to five rows.

Usage

<dl class="bog-static-list">
  <div class="bog-static">                       <!-- data-type="blank" · data-disabled · data-state="skeleton" -->
    <dt>Interest rate</dt>
    <dd>9.50 % <span class="bog-tooltip" data-align="right">…</span></dd>
  </div>
</dl>
