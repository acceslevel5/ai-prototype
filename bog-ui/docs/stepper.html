Numeric Stepper

Open in Figma ↗

Adjusts a small number within limits — passengers, cards, months — with − and + buttons. At the minimum − is disabled, at the maximum +. Loading shows a spinner in place of the value while it's saved. An optional helper sits right-aligned underneath.

Usage

<div class="bog-stepper" data-min="1" data-max="5">          <!-- data-state="loading | skeleton" · data-disabled -->
  <button class="bog-icon-btn" data-type="neutral" data-size="small" aria-label="Decrease" data-step="-1"><span class="bog-icon" data-icon="minus"></span></button>
  <output class="bog-stepper__value">1</output>
  <button class="bog-icon-btn" data-type="neutral" data-size="small" aria-label="Increase" data-step="1"><span class="bog-icon" data-icon="plus"></span></button>
</div>

Try it

Press − and + — the button dips and springs back, and the digits that change roll (+ down, − up). Go past 9 to see only the changing digit move; at 0 or 20, press the greyed-out button to see the number shake.

Motion

A press dips the button to 90% and springs it back with a small overshoot (333 ms). The old number slips 3.75 px and fades out fast; the new one follows 33 ms later from the other side. + moves the digits down, − moves them up. Source: Numeric Stepper ↗

A stepper view: the button press is a two-step scale; the number uses a numeric content transition with the guide's curve (iOS rolls only the digits that change).

A composable with an Animatable for the press and AnimatedContent for the number.

Built into bog-ui.js (Web Animations API). Nothing to call — every .bog-stepper gets it.
