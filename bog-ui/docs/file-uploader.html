BOG UI

File uploader

Open in Figma ↗

Adds several files of one kind for one purpose — receipts for an insurance claim. It shows the limits first, then lists each file with its progress, result and × to remove it; a failed file gets Retry. Rows come in Default, Media (with a thumbnail) and Compact. For named documents with their own rules, use File Attachment.
