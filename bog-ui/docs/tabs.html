BOG UI

Tabs

Open in Figma ↗

Switch between related groups of content on the same screen — one panel at a time. The selected tab gets an orange underline and a bold label. Fixed: two or three tabs sharing the width. Wrapped: up to five, each as wide as its label; the row scrolls. Same content in another period or view → Segmented Control.

Usage

<div class="bog-tabs" role="tablist">               <!-- data-type="wrapped" -->
  <button class="bog-tab" role="tab" aria-selected="true" aria-controls="p-history">History</button>
  <button class="bog-tab" role="tab" aria-selected="false" aria-controls="p-details">Details</button>
  <button class="bog-tab" role="tab" aria-selected="false" aria-controls="p-limits">Limits</button>
</div>
<section id="p-history" role="tabpanel">…</section>
<section id="p-details" role="tabpanel" hidden>…</section>
