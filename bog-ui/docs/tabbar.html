BOG UI

Tab Bar

Open in Figma ↗

The app's main navigation on iOS: a floating glass pill with five destinations. The current page shows a filled icon, a bold label and a light pill behind it; a red dot flags something new. Use the Dark mode over darker content.

Usage

<nav class="bog-tabbar" aria-label="Main">                 <!-- data-mode="dark" -->
  <div class="bog-tabbar__bar">
    <a class="bog-tabbar__item" href="#" data-page="home" aria-current="page">Home</a>
    <a class="bog-tabbar__item" href="#" data-page="my-space">My Space</a>
    <a class="bog-tabbar__item" href="#" data-page="payments" data-badge>Payments</a>
    <a class="bog-tabbar__item" href="#" data-page="offers">Offers</a>
    <a class="bog-tabbar__item" href="#" data-page="hub">Hub</a>
  </div>
</nav>
