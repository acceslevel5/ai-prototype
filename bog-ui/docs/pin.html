BOG UI

PIN code Input

Open in Figma ↗

Asks for a short numeric PIN: a title, a helper line and one dot per digit that fills as users type — from the phone's keyboard or from Keyboard Numeric. Error turns the dots and the helper red and gives a short shake. Themed, White Static and Black Static.

Usage

<label class="bog-pin">                              <!-- data-appearance="white | black" · data-state="error" -->
  <span class="bog-pin__title">Enter your PIN</span>
  <span class="bog-pin__helper">Please enter your 4-digit code</span>
  <span class="bog-pin__dots"><i></i><i></i><i></i><i></i></span>
  <input class="bog-pin__input" id="pin" type="password" inputmode="numeric" maxlength="4">
</label>
<script>
  pin.closest(".bog-pin").addEventListener("pincomplete", (e) => { /* check e.detail.value */ });
</script>

Try it

Type with the keypad (or your keyboard). The right PIN is 1234 — anything else shows the error.
