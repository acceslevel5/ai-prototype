Feature Notes Page

Open in Figma ↗

What's new after an update: a large picture, slider dots, a title, a short description and one button, on a full screen users close with ×. Several notes swipe sideways; the button goes to the next one with the Slide motion (the new picture sweeps over the old one while the text drifts across) and, on the last, finishes.

Motion

Next slides to the following note in about half a second — try it in the phone on the right. The new picture sweeps in from the right edge and covers the old one, which leaves to the left 50 ms behind it. The old text drifts 50 px left as it fades; the new text arrives from 50 px to the right and fades in a little later. Source: Feature Note – Slide ↗

Keep the current and next index in state; draw both notes in a ZStack (next on top) and drive each layer with its own timing curve. When the longest one ends, drop the old note.

One Animatable per layer, launched together with their own delays; the pager jumps to the next page when they finish.

Built into bog-ui.js: the Next button plays it (Web Animations API). Nothing to call; BOG.notesGo(root, index) plays it from code.
