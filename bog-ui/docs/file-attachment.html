BOG UI

File Attachment

Open in Figma ↗

One row per named document — proof of income, a passport photo. Tap the row to choose a file or take a photo; it shows progress, then a preview with Delete and Replace. Errors stay in the row and say what to fix. Read-only for submitted files. Several files of one kind → File uploader.
