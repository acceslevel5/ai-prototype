BOG UI

Sticky Bar

Open in Figma ↗

The bottom action area of a screen. Content scrolls under it and fades out above the buttons. Holds the main action (and a second one, or an icon button beside it), an optional helper line or slot, and the iOS home indicator. Black appearance for dark screens; Overlay placement for sheets and modals.

Usage

<footer class="bog-stickybar">                    <!-- data-appearance="black" · data-placement="overlay" -->
  <p class="bog-stickybar__helper">You can cancel any time</p>
  <div class="bog-stickybar__buttons">
    <button class="bog-btn" data-type="primary" data-width="fill">Continue</button>
  </div>
  <span class="bog-stickybar__home"></span>
</footer>
