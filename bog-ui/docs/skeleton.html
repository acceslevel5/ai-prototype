Skeleton

Open in Figma ↗

Grey placeholders that hold the layout while content loads, so the screen doesn't jump when it arrives. Every component has its own skeleton state (data-state="skeleton"); use these pieces for custom layouts. The bar heights stand in for the text styles they replace.

Usage

<span class="bog-skeleton"></span>                              <!-- 48×48 block; data-shape="circle" -->
<span class="bog-skeleton-text" data-style="heading"></span>
<div class="bog-skeleton-paragraph"></div>                     <!-- data-size="small" -->
