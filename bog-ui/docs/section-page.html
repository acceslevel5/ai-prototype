BOG UI

Section Page

Open in Figma ↗

The layout most screens are made of: sections 32 px apart, each a header — a title, an optional description, a notification dot, a chevron when the header opens more, and a button on the right — over its content. Widget (BETA) puts a section in a white card for the home screen.

Usage

<main class="bog-section-page">
  <section class="bog-section">                                <!-- data-size="small" · data-state="skeleton" -->
    <header class="bog-section__header">
      <a class="bog-section__heading" href="…">                  <!-- a div when the header doesn't open anything -->
        <h2 class="bog-section__title">Added cards</h2>
        <p class="bog-section__desc">Description</p>
      </a>
      <button class="bog-btn" data-type="neutral" data-size="small">Button</button>   <!-- optional -->
    </header>
    <div class="bog-section__content">…</div>
  </section>
</main>
