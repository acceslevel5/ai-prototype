Amount

Open in Figma ↗

Balance with currency symbol, optional currency selector and per-currency account balances. Pressing the amount (the up/down arrows) switches it to the next currency, converted, with a short vertical roll. White static is shown on orange, Inverse on dark.

Usage

<div class="bog-amount" data-size="large" data-rates='{"₾":1,"$":0.37,"€":0.32,"£":0.28}'>   <!-- rates: optional, convert on switch -->
  <button type="button" class="bog-amount__main">                <!-- press (or ↑ / ↓) → next currency -->
    <span class="bog-amount__value">1,000.00</span>
    <span class="bog-amount__currency">₾</span>
    <span class="bog-amount__selector"></span>
  </button>
  <div class="bog-amount__balances">
    <span class="bog-amount__balance" data-active><span class="bog-amount__num">2.00</span>₾</span>
    <span class="bog-amount__balance"><span class="bog-amount__num">0.00</span>$</span>
  </div>
</div>
<script>
  amount.addEventListener("currencychange", (e) => { /* e.detail.currency, e.detail.value */ });
  BOG.amountCurrency(amount, "€");   // switch from code
</script>

Try it

Press the amount — or focus it and use ↑ / ↓ — to switch currency. The value converts with the rates in data-rates (₾ 1 · $ 0.37 · € 0.32 · £ 0.28 here) and the digits roll like an odometer: each one's 0–9 strip slides to the new digit with a springy overshoot while it sharpens from a slight blur (look from bencho.dev's Time scrubber). The symbol rolls up and out (↑ reverses it), and when the number gets shorter or longer the symbol and arrows glide to their new place with the same springy curve instead of jumping. Switch to Simple to compare with the plain vertical roll.
