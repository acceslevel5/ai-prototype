BOG UI

Loading Spinner

Open in Figma ↗

Shows that something is loading when you can't say how long it will take. Five sizes, an optional "Loading..." label, and colours for light surfaces, dark surfaces and imagery. Disabled shows a still grey ring. For known progress use Progress Bar or Progress Circular.

Usage

<div class="bog-spinner" data-size="large" role="status">      <!-- data-type="inverse | static-primary | white" · data-disabled -->
  <span class="bog-spinner__ring"></span>
  <span class="bog-spinner__label">Loading...</span>
</div>
